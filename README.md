# 毛茸茸的不在场证明

手机竖屏像素动物探案游戏。30 个递进案件，16 种现场主题。

首页以双列像素信封展示各案真实地图。未打开的案件为未拆封信封；已打开的案件为拆封纸卡，并显示已保存的动物与公共排除标记。纸张素材由 imagegen 生成并优化为小体积 PNG，文字和案件状态由游戏数据实时显示。

首页直接展示信封案卷；第一次打开任意案件时，显示六页图解入门，可跳过或关闭并记住已读状态，再进入该案介绍。“玩法手册”包含玩法、关键词、工具、常见问题四栏，以及本案实际动物、道具和区域图例，也可重新打开六页引导。

全部案件保持原地图、正确落点、凶手与推理策略等级。前五案按要求恢复到信封版原有的简单入门配置；第六案起检查过早指认问题，任取一位或两位非受害者的完整证词，加上地图、全部通用线索和受害者现场记录，均仍存在其他凶手可能。游戏进度兼容原存档，仅清理已变更证词的旧核对勾选。

第 6 案起逐步加入组合否定与“或”证词，例如“在库房，不挨着展厅凳”“在两个物件之一旁”。“或”表示至少满足一项，两项都满足也成立；旁边只计算同一区域的上下左右。前 5 案恢复此前入门配置，不加入这些复杂表达。受害者证词统一明确写“只与凶手同区”，区域内总共只有受害者和凶手。

第 13–22 案每案加入 1 条通用线索，第 23–30 案每案 2 条，共 26 条，紧凑常显在地图下方。通用线索统计全体动物（包括受害者），内容涉及区域、外圈及道具上的动物数、道具旁的动物数。同一个动物在一条线索中只计一次。它们参与现场校验和提示；删除全部通用线索后该案将出现多个解，每条通用线索也实际参与排除。原有每行每列恰好一位的规则保留。

- 点击动物证词，再点击地图格子放置；证词位于地图下方。满足全部证词后指认凶手。
- 工具栏提供放置、公共排除标记、逐格擦除、撤销和提示。排除标记切换动物后仍显示；擦除会清掉所点格的动物及全部标记，保留场景道具，可撤销、重做。
- 地图下方“辅助：开/关”或游戏设置可切换辅助判定。关闭后允许试放到行列或道具冲突的位置，提交时再检查；开关和试放进度刷新后保留。候选功能已移除，旧排除标记会合并为公共标记。
- 游戏设置提供独立的操作音效、背景音乐开关与音量，并可试听。原创背景曲《午夜案卷》为72 BPM、约53秒的柔和像素侦探循环；拆信封、选择、落子、排除、擦除、撤销、重做、提示、检查、错误反馈及结案共有11类短音效。保留原有静音选择，点击后才启用声音，切到后台或离开页面暂停。音乐与音效由包内代码合成，无需下载外部音频。
- 进度保存在当前浏览器中；存档管理支持复制和粘贴 JSON 备份。换设备、清除浏览器数据或更换网址前请备份。
- 纯静态网页，无账号、无后端和小红书依赖。资源均包含在仓库中。
- 手机浏览器可选择“添加到主屏幕”；manifest 声明竖屏偏好。网页仍支持窗口变化。

## 本地运行与更新

在本目录启动任意静态 HTTP 服务，打开 index.html。GitHub Pages 从 main 分支根目录发布，推送后自动更新。

游戏逻辑与关卡文件为 engine.js、cases.js、props.js；界面入口 app.js；浏览器存储适配 web.js。字体许可证见 licenses/。
