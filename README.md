# 毛茸茸的不在场证明

手机竖屏像素动物探案游戏。30 个递进案件，16 种现场主题。

- 在线试玩：https://golite369.github.io/fluffy-alibi/
- 手机扫码打开同一游戏地址：

  ![手机扫码试玩](share/qr.png)

- 点击动物证词，再点击地图格子放置；证词位于地图下方。满足全部证词后指认凶手。
- 进度保存在当前浏览器中；存档管理支持复制和粘贴 JSON 备份。换设备、清除浏览器数据或更换网址前请备份。
- 纯静态网页，无账号、无后端和小红书依赖。资源均包含在仓库中。
- 手机浏览器可选择“添加到主屏幕”；manifest 声明竖屏偏好。网页仍支持窗口变化。

## 本地运行与更新

在本目录启动任意静态 HTTP 服务，打开 index.html。GitHub Pages 从 main 分支根目录发布，推送后自动更新。

游戏逻辑与关卡文件为 engine.js、cases.js、props.js；界面入口 app.js；浏览器存储适配 web.js。字体许可证见 licenses/。
